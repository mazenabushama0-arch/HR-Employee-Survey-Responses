# HR Employee Survey Responses (Power BI)

> 🌐 Part of my data analytics portfolio:[My-PORTFOLIO](https://mazenabushama0-arch.github.io/Portfolio/) · 👤 [More projects on my GitHub](https://github.com/mazenabushama0-arch)

A 7-page Power BI report analyzing employee survey responses by department, role, and question, covering both participation (completion) and sentiment (average response).

## Business questions

- What is the overall survey completion rate, and how does it differ by department?
- Which roles (Director, Manager, Supervisor, Staff) respond most positively or negatively?
- Which survey questions score highest and lowest?
- How do departments compare on average response, completion rate, and number of responses?

## Dashboard pages

| Page | What it shows |
|---|---|
| **Over View** | Survey completion rate, response status split, completed responses by department |
| **Roles Analysis** | Participants by role, average response by role, average response by role across questions |
| **Matrex** | Matrix of average response by question and department |
| **By Question** | Average response per question with a question slicer and a breakdown by role |
| **Department** | Average response by department with a summary table (average response, completion rate, response count) |
| **Count by Department** | Scatter comparing average response, completion rate, and response count by department |
| **Role Sentiment** | Average response by role (Director, Manager, Staff, Supervisor), trend across questions, and role × department matrix |

## Key measures

`Completion Rate` · `Total Responses` · `Total Participants` · `Avg Response by Role` · `Avg Response by Question` · `Avg Response by Department` · `Responses Count by Department`

## Tech stack

- Power BI Desktop
- DAX measures

Download `HR Employee Survey Responses.pbix` and open it with the latest Power BI Desktop.
